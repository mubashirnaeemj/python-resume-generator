# Python CV Generator

Generate a professional PDF CV using **Python** and **ReportLab**.

## Features

- Generates a clean one-page PDF CV
- ATS-friendly layout
- Custom styling and formatting
- Easy to edit and customize


## Usage

Run the script:

```bash
python cv_update.py
```

After running the script, the generated PDF will be saved as:

```text
CV.pdf
```
